# Соучастник

Клавиатура для Android. Пока вы печатаете — в строке над клавишами висит
статья КоАП или УК РФ и наказание за то, что вы пишете.

> Это не юридическая консультация. Настоящий суд смешнее.

```
┌──────────────────────────────────────────────┐
│ ст. 5.61 КоАП · оскорбление · 3–5 тыс ₽    ◉ │
├──────────────────────────────────────────────┤
│  й ц у к е н г ш щ з х ъ                     │
└──────────────────────────────────────────────┘
```

## Ничего не уходит с телефона

**У приложения нет разрешения `android.permission.INTERNET`.** Не обещание,
а проверяемый факт — приложение технически не способно отправить наружу ни
один байт:

```bash
aapt dump permissions app-release.apk     # список пустой
```

Модель работает целиком на устройстве. Поля с паролями не разбираются.

## Как это работает

| | |
|---|---|
| Модель | Qwen3.5-0.8B, LoRA, Q4_K_M, llama.cpp на CPU |
| Вывод | статья = один токен-метка, argmax по логитам меток |
| Кандидаты | словарь `assets/triggers.json` сужает 82 статьи до нескольких ещё до модели |
| Наказания | из `assets/articles.json`, не из генерации |
| Требования | Android 9+, arm64, 6 ГБ RAM |

Тумблер в строке выключает разбор; выключено — состояние по умолчанию.
В выключенном виде модель не загружается в память. Движок живёт в отдельном
процессе: если его убьют по памяти, строка гаснет, а клавиатура работает.

## Сборка

```bash
git submodule add https://github.com/ggml-org/llama.cpp third_party/llama.cpp
./gradlew assembleRelease
```

Ревизия llama.cpp закреплена в `tools/llama-cpp-pin.txt` — нужна сборка с
поддержкой архитектуры `qwen35`.

Собирается и без весов: клавиатура работает, строка показывает «модель не
установлена». Куда положить модель —
[`app/src/main/jniLibs/README.md`](app/src/main/jniLibs/README.md).

## Модель

Дообученный адаптер в репозиторий не входит. Формат запроса задан в
`llama_bridge.cpp`: системная часть из `assets/prompt.txt`, затем сообщение
в `<msg>…</msg>`. Ответ — один токен-метка из поля `label` в
`assets/articles.json`. Сборка GGUF из адаптера — `tools/make_gguf.sh`.

## Границы

Приложение констатирует, а не помогает обойти. Выдуманных статей в
справочнике нет: уголовной статьи за использование VPN не существует
(ближайшее реальное — 13.53 КоАП и ст. 63 УК), наказания пользователю за
Telegram тоже. Статьи о преступлениях против несовершеннолетних и половой
неприкосновенности не включены.

Слова в `assets/triggers.json` — корни для детекции, как в любом фильтре
нежелательного контента: перечень того, что приложение должно распознавать.
